# Amazon Clone (UI only)

A static front-end clone of the Amazon homepage built using **pure HTML and CSS**.  
This project focuses on layout design, responsiveness, and UI replication.

---

## 📌 Project Overview

This Amazon Clone replicates the visual structure and layout of the Amazon website, including:

- Header with logo, search bar, and navigation
- Product sections and cards
- Footer with multiple links
- Clean and responsive design

The purpose of this project is to strengthen **HTML & CSS fundamentals**, especially:
- Flexbox
- Box model
- Positioning
- Responsive layouts

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**

---

## 🎯 Features

- Amazon-like homepage layout
- Fully responsive design
- Clean UI using Flexbox
- Product grid layout
- Footer with multiple columns
- Pixel-focused styling
